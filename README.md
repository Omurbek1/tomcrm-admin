# TomStore — Панель платформы (tomstore-admin)

Отдельный фронт для управления ВСЕМИ компаниями SaaS (SaaS Этап 5). Не путать
с CRM (`tomstore-crm`) — та для одной компании. Панель ходит в бэкенд
`tomstore-backend` по эндпоинтам `/api/platform/*`.

## Стек
Vite + React 19 + Ant Design 6 + React Query.

## Запуск
```bash
cp .env.example .env      # укажите VITE_API_URL (адрес бэкенда)
npm install
npm run dev               # http://localhost:5199
```

## Авторизация
Вход ПОЛНОСТЬЮ отдельный от CRM: платформенный токен на своём секрете
`PLATFORM_JWT_SECRET`. Учётки администраторов хранятся в БД (таблица
`platform_admins`), а НЕ в env — заводятся и меняются прямо в панели
(раздел «Администраторы»).

- Стартовый админ создаётся миграцией: логин `admin`, пароль `admin`
  (со флагом «сменить пароль»). **Смените пароль при первом входе.**
- `PLATFORM_JWT_SECRET` в env бэкенда — секрет подписи токена (в проде
  задать обязательно; есть dev-фолбэк, поэтому без env панель тоже
  работает локально).

## Возможности v1
- Обзор: всего компаний, активные, триал истекает ≤3 дн., триал истёк.
- Список компаний: поиск (название/slug/телефон), фильтр по статусу,
  счётчики сотрудников/сделок.
- Карточка компании: расход по лимитам, смена статуса, продление триала
  (+7/+14/+30 дн.), смена тарифа. Все действия сбрасывают кэши бэкенда.
- Администраторы: список, добавить, включить/выключить, сменить пароль,
  удалить (нельзя отключить/удалить последнего активного или удалить себя).
